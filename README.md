# 📝 Java Swing To-Do List

A simple and intuitive **To-Do List application built using Java Swing**.  
This project demonstrates GUI design, event handling, and file persistence in Java, allowing users to **add, remove, and manage tasks efficiently**.

---

## 🚀 Features

- ➕ Add new tasks  
- ✅ Mark tasks as completed  
- ❌ Delete tasks  
- 💾 Optional: Save and load tasks from a file  
- 🪟 Clean and responsive Swing-based user interface  

---

## 🛠️ Technologies Used

- **Java 8+**
- **Swing** (for GUI)
- **AWT** (for event handling and layout management)
- **File I/O** (optional, for task persistence)
